Glacier Bay Python environment setup

Run from the glacierbay_alaska repository root (not from envs/).
If needed: cd /path/to/glacierbay_alaska
Use the terminal on the machine where the notebooks will run (including over SSH).

1. Create glacierbay once, using Conda or Mamba:
   conda env create -n glacierbay -f envs/environment.yml
   # Mamba alternative: mamba env create -n glacierbay -f envs/environment.yml
   # If glacierbay already exists, activate it; do not recreate it.

2. Activate it for every project session:
   conda activate glacierbay

3. Register the notebook kernel once:
   python -m ipykernel install --user --name glacierbay --display-name "Python (glacierbay)"

4. In VS Code, install the Python and Jupyter extensions if needed.
   Open 4_explore_hrrrak_netcdf.ipynb, select glacierbay as its kernel, and Run All.
   The cleaned sample is included; downloading and notebooks 1-3 are not required
   for this first exploration. Save outputs so figures show on GitHub.
   Alternatively start JupyterLab from the repository root:
   jupyter lab

5. When finished:
   conda deactivate

Separate tools for downloading additional data (Linux): Bash, curl, GNU Parallel,
GNU date/coreutils, awk, grep, and wgrib2. These are not installed by the Python
environment file. See hrrrak/download_hrrrak_readme.txt for checks and commands.
